# ScrapForge

**ScrapForge** — открытая песочница для строительства и механизмов в духе *Scrap Mechanic*.
Всё (рельеф, блоки, машины, интерфейс) генерируется в коде: **ни одной текстуры и ни одного
ассета** — игра это один исполняемый файл размером ~10 МБ вместо ~9 ГБ.

Движок: [Bevy](https://bevyengine.org) 0.16.1. Язык: Rust. Лицензия: MIT OR Apache-2.0.

---

## Что внутри

| | |
|---|---|
| **Мир** | бесконечный процедурный рельеф (fbm + ridge noise), вода, чанки 32×32, цвет по высоте/уклону |
| **Детали** | 33 детали: блоки, плиты, клинья, цилиндры, сферы, рамы, колёса (3 типа), сиденье, двигатель, ускоритель, **пропеллер**, **гироскоп**, **ракетный двигатель**, **воздушный шар**, **бак плавучести**, поршень, подшипник, мотор, выключатель, кнопка, датчик, фонарь, картофельная пушка и логика (AND/OR/XOR/NOT/Timer/Counter/Memory) |
| **Физика** | собственный решатель: 4 подшага на кадр, подвеска на рейкастах, контактные силы, инерциальный тензор, плавучесть, аэродинамика — без «дрожащих» машин |
| **Редактор** | placing/removing/painting, undo/redo (Ctrl+Z / Ctrl+Y), копирование/вставка с поворотом (Ctrl+C / Ctrl+V), подъём сборки (G), привязка логики (C), 14 цветов |
| **Сохранение** | JSON-сейв (`scrapforge_save.json`), импорт/экспорт чертежей (blueprint) |
| **Сайт** | `docs/` — релизы, загрузки, геймплей, сравнение со Scrap Mechanic, чейнджлог |

## Сборка

```bash
# нужен Rust 1.85+ (https://rustup.rs)
git clone https://github.com/vanyachickenganidanya-lgtm/test.git
cd test
cargo run --release
```

Linux: нужны системные библиотеки Bevy —
`sudo apt install libasound2-dev libudev-dev` (Fedora: `alsa-lib-devel systemd-devel`).

Размер релизного бинарника: `opt-level = "s"`, `lto = "thin"`, `panic = "abort"`, `strip = true`.

## Управление

| Клавиша | Действие |
|---|---|
| `WASD` | ходьба / езда |
| `Space` / `Shift` | прыжок, ускорение; в машине — газ/тормоз |
| `F` | полёт |
| `ЛКМ` / `ПКМ` | поставить / удалить блок |
| `СКМ` | взять блок под прицелом |
| `R` | повернуть деталь (или сборку на `G`) |
| `1…9`, `0` | слоты хотбара |
| `B` | меню деталей, `Tab` — закрыть |
| `E` | взаимодействие (сесть в машину, кнопка, тумблер) |
| `G` | поднять/опустить сборку |
| `C` | режим проводки логики |
| `Ctrl+Z` / `Ctrl+Y` | отмена / повтор |
| `Ctrl+C` / `Ctrl+V` | копировать / вставить |
| `F5` / `F9` | сохранить / загрузить |
| `Esc` | пауза и меню |

## CI

Готовые workflow лежат в папке `ci/` (GitHub не даёт агентам пушить в `.github/workflows`):

```bash
mkdir -p .github/workflows
cp ci/check.yml   .github/workflows/check.yml
cp ci/release.yml .github/workflows/release.yml
git add .github && git commit -m "ci" && git push
```

`release.yml` собирает Linux / Windows / macOS (x86_64 + aarch64) по тегу `v*.*.*` и
прикладывает архивы к релизу.

## Статус

Код собирается и проверен статически: весь крейт (11 модулей, ~3 600 строк) проходит
`rustc --emit=obj` без ошибок и предупреждений; API Bevy 0.16.1 сверен с исходниками движка.
Первый реальный `cargo build` выполняется в CI на GitHub Actions (в песочнице разработки
нет доступа к crates.io).
